==========================================
PORT 5000 ERROR SOLUTION
==========================================

ERROR MESSAGE:
"Error: listen EADDRINUSE: address already in use :::5000"

MEANING:
Port 5000 already use ho raha hai kisi aur process se. Backend server start nahi ho sakta.

==========================================
SOLUTION STEPS (Windows)
==========================================

METHOD 1: Find and Kill Process Using Port 5000
-------------------------------------------------

Step 1: Open Command Prompt (CMD) or PowerShell
   - Press Windows + R
   - Type: cmd
   - Press Enter

Step 2: Find Process Using Port 5000
   Run this command:
   
   netstat -ano | findstr :5000
   
   This will show output like:
   TCP    0.0.0.0:5000    0.0.0.0:0    LISTENING    12345
   
   Note the last number (PID) - example: 12345

Step 3: Kill the Process
   Run this command (replace 12345 with your PID):
   
   taskkill /PID 12345 /F
   
   OR use this command to kill all Node.js processes:
   
   taskkill /F /IM node.exe

Step 4: Start Backend Again
   Go to your project folder and run:
   
   cd backend
   npm start
   
   OR
   
   node index.js

-------------------------------------------------

METHOD 2: Change Backend Port (Alternative Solution)
-------------------------------------------------

If you want to use a different port instead:

Step 1: Open this file:
   backend/index.js

Step 2: Find this line (usually around line 100-200):
   const PORT = process.env.PORT || 5000;

Step 3: Change it to:
   const PORT = process.env.PORT || 5001;

Step 4: Save the file

Step 5: Update frontend API configuration
   Open: frontend/src/config/axios.ts
   
   Find: baseURL: 'http://localhost:5000'
   Change to: baseURL: 'http://localhost:5001'

Step 6: Start backend:
   cd backend
   npm start

-------------------------------------------------

METHOD 3: Quick Fix - Kill All Node Processes
-------------------------------------------------

Step 1: Open PowerShell (Run as Administrator)

Step 2: Run this command:
   Get-Process node | Stop-Process -Force

Step 3: Start backend again:
   cd backend
   npm start

==========================================
FILES TO CHECK
==========================================

1. backend/index.js
   - Check PORT configuration
   - Usually line: const PORT = process.env.PORT || 5000;

2. frontend/src/config/axios.ts
   - Check API baseURL
   - Should match backend port

3. .env file (if exists)
   - Check PORT variable
   - Should be: PORT=5000

==========================================
PREVENTION TIPS
==========================================

1. Always stop backend server properly:
   - Press Ctrl + C in terminal
   - Don't just close terminal window

2. Check if port is free before starting:
   netstat -ano | findstr :5000
   
   If no output, port is free

3. Use different ports for different projects:
   - Project 1: 5000
   - Project 2: 5001
   - Project 3: 5002

==========================================
QUICK COMMANDS REFERENCE
==========================================

Find process on port 5000:
   netstat -ano | findstr :5000

Kill specific process (replace PID):
   taskkill /PID <PID> /F

Kill all Node.js processes:
   taskkill /F /IM node.exe

Kill all Node.js (PowerShell):
   Get-Process node | Stop-Process -Force

Check if port is free:
   netstat -ano | findstr :5000
   (No output = port is free)
